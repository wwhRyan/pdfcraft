关于此工具

页码为您的PDF文档添加可自定义的页码编号。从各种格式、位置和样式中选择以匹配您文档的设计。

您可以设置起始编号、跳过某些页面并使用不同的编号格式（1, 2, 3 或 i, ii, iii）。非常适合创建具有正确分页的专业文档。

所有处理都在您的浏览器本地进行，确保您的文档保持私密。

常见问题

可以跳过第一页吗？

是的，您可以指定要编号的页面和要跳过的页面，如标题页或封面页。

有哪些编号格式可用？

您可以使用阿拉伯数字（1, 2, 3）、罗马数字（i, ii, iii 或 I, II, III）或字母（a, b, c）。

可以添加"第X页，共Y页"格式吗？

是的，您可以在编号格式中包含总页数。
