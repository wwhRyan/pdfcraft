About This Tool

「カスタム角度で回転」は、PDFページの向きを細かく制御できるツールです。90度単位の標準的な回転とは異なり、任意の角度を入力して回転させることができます。

スキャナーで斜めに読み取られたドキュメントの補正や、図面やチャートの微調整に最適です。特定のページのみ、またはドキュメント全体に適用できます。

How to Use

  1. 1

    PDFをアップロード

    回転させたいページを含むPDFファイルをアップロードします。

  2. 2

    角度を設定

    各ページの正確な回転角度を入力するか、一括設定を行います。

  3. 3

    プレビューと調整

    リアルタイムプレビューを確認しながら、水平・垂直を合わせます。

  4. 4

    適用してダウンロード

    「回転」をクリックして変更を適用し、補正されたPDFをダウンロードします。

Use Cases

スキャン書類の補正

スキャナーに斜めに入ってしまった書類を真っ直ぐに直します。

テクニカル図面

技術図面や設計図の向きを精密に調整します。

クリエイティブなレイアウト

ページを特定の芸術的な角度に回転させてユニークな資料を作成します。

Frequently Asked Questions

45.5度のような小数点以下の角度で回転できますか？

現在、ツールは整数の度数のみサポートしていますが、小数点以下の精度を可能にするよう取り組んでいます。

ページの内容に影響しますか？

内容は視覚的に回転されます。ページサイズは回転した内容に合わせて自動的に調整されます。

1ページだけ回転できますか？

はい、他のページはそのままで、個々のページにカスタム回転角度を設定できます。
